# Newsletter Issues 📧

This folder contains all published and draft newsletter issues.

## Structure
- `drafts/` - Work-in-progress newsletters
- `published/` - Completed newsletters by date
- `templates/` - Newsletter templates and formats

## Naming Convention
- Draft: `YYYY-MM-DD-draft-topic.md`
- Published: `YYYY-MM-DD-issue-N-title.md`

Each issue should include:
- Clear, actionable insights about AI tools
- Real business examples
- Practical implementation steps
- Resource links and further reading
